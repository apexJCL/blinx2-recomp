## Context

The work uses one worktree set, `wt/save-import/{cat,xboxrecomp-cli}`, with
a feature branch in each. The toolkit is read-only. The gates are the CLI's
`uv run pytest tests` with its ruff checks, `wizard/check.sh` for phase 3,
and cat's `uv run pytest scripts` with ruff. All fixtures are synthetic,
generated by test code. Real saves, HDD images and `cat/user-logs/` are
never read, copied or committed. Runs go to `xbox-recomp/runs/save-import/`.
Every merge is a squash with a review first. The user answered the
design's open questions on 2026-10-18; the answers are in `design.md`.
