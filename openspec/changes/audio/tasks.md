Conventions: every task names the repo and branch it lands in. `cat` = this repo, worktree `wt/audio/cat`, branch `audio/spec`. `toolkit` = `wt/audio/xboxrecomp`, branch `audio/main` (one upstream PR; no title constants). `[P]` marks tasks that can run in parallel with the other `[P]` tasks of the same phase. Game runs happen only on the Linux/Proton host (`ssh <bench-host>`, `scripts/bench.sh` under the run lock `~/.recomp-run.lock`), one at a time, and never on the user's own xemu. Dumps, captures and logs stay local and gitignored; evidence quoted in a task's commit message is log lines and numbers, never game data.
