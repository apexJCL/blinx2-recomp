## Context

BLX-118. One worktree trio `wt/shaderpc/{cat,xboxrecomp,xboxrecomp-cli}`, one
agent: the toolkit off `posix-host/portability`, the CLI off `main`, cat off
`main`. Mac builds with `export DEVELOPER_DIR=/Library/Developer/CommandLineTools`;
every Mac run through `sh notes/mac-run-lock.sh` with `SDL_AUDIODRIVER=dummy`
and no sound without asking; runs under `xbox-recomp/runs/shaderpc/`, never
inside a worktree. The Linux/Proton through `blinx2 bench`, which takes the lock
itself; the Deck only by the user, from a scratch root. Every merge is a
squash after an Opus review, followed by the post-merge steps of CLAUDE.md
(notes to `notes/shaderpc/`, worktree removed, branch kept,
`blinx2 bench integrate --golden`, TASKS.md). Sizes: S up to half a day,
M one to two days.

Merge order (design D1, D8): toolkit (group 2) first, named for the next
public toolkit round; then the CLI (group 3) merged and tagged locally;
then cat (group 1), whose `game.toml` bumps `[toolkit]` and `[cli]` and
adds `[shaders]` in one commit; then the verification runs (group 4). The
CLI's **public** push round, which carries the launcher export lines, waits
for 4.2 (the seeded goldens) to pass, and cat's public round comes after
the CLI's. Group 5 is the orchestrator's, in the main checkouts.
