## Context

`feat/config-layering` in each, one agent. Toolkit off
`posix-host/portability`, CLI off `main`, cat off `main`. Mac builds with
`export DEVELOPER_DIR=/Library/Developer/CommandLineTools`; Mac runs
headless with `SDL_AUDIODRIVER=dummy`. Runs and bundle checks go to
`xbox-recomp/runs/configlayer/`, never inside a worktree. The Linux/Proton runs
wait for the orchestrator's "go" and hold `flock -w 3600 ~/.recomp-run.lock`
(`blinx2 bench` takes it itself). Every merge is a squash with an Opus
review first (CLAUDE.md). The design's open questions are recorded
decisions (the user, 2026-10-11).
