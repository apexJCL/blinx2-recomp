## Context

Phases of design.md "Migration Plan", one worktree set per phase
(`wt/<phase>/{cat,xboxrecomp,xboxrecomp-cli}`), toolkit branches off
`posix-host/portability`, CLI off `main`, cat off `main`. Mac builds with
`export DEVELOPER_DIR=/Library/Developer/CommandLineTools`; headless runs
with `SDL_AUDIODRIVER=dummy`. Dumps, packs, inventories with texels and
frame dumps go to `xbox-recomp/runs/texup/`, never inside a worktree or a
repository. Proton runs on the Deck when the orchestrator sends "go".
Every merge gets a review; fixes go back to the phase's agent.
