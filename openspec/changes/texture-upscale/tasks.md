## Context

Phases of design.md "Migration Plan", one worktree set per phase
(`wt/<phase>/{cat,xboxrecomp,xboxrecomp-cli}`), toolkit branches off
`posix-host/portability`, CLI off `main`, cat off `main`. Mac builds with
`export DEVELOPER_DIR=/Library/Developer/CommandLineTools`; headless runs
with `SDL_AUDIODRIVER=dummy`. Dumps, packs, inventories with texels and
frame dumps go to `xbox-recomp/runs/texup/`, never inside a worktree or a
repository. Proton runs on the Deck when the orchestrator sends "go".
Every merge gets a review; fixes go back to the phase's agent.

- [ ] 1.5 The dump (D1): `nv2a_tex_dump.{c,h}` in the kernel library; both `tex_upload`s call `nv2a_tex_dump_upload(stage, hash, decoded_levels)` only when the `tex_dump` debug entry names a directory; one file per hash written once (`<hash>.xtd`: a 64-byte header, then the decoded A8R8G8B8 levels) and `<hash>.json` (hash, w, h, levels, format name, pitch, swizzled/linear/dxt, palette yes/no, wrap u/v, min/mag filters, first-seen flip); a per-address distinct-hash counter marks `volatile` after 8 hashes and stops writing that address; stages bound to a render target skip with a count; `[TEXDUMP]` summary every 600 flips and at exit (written, skipped rt, skipped volatile, skipped linear). The CPU backend says once that it does not dump.
- [ ] 1.5a The magnification trace (D14): `RECOMP_TRACE=tex_mag` adds one compile-time flag to the combiner shader of both backends that takes the texcoord derivatives in uniform control flow, then on one pixel in 64 computes the stage's unclamped LOD (`calculate_unclamped_lod` / `CalculateLevelOfDetailUnclamped`) and does an atomic max of the biased unsigned encoding of `-lod` into one device buffer with a slot per draw id and stage for the frame (D3D11: a PS UAV bound with `OMSetRenderTargetsAndUnorderedAccessViews` on the trace's pipelines; Metal: a device buffer). The backend reads the buffer back when the command buffer completes (Metal) or from a staging copy one frame behind (D3D11), never per draw, and folds it into a per-hash table (max magnification, draws, the run's render scale), dividing by the entry's scale when a pack entry was bound; pre-transformed batches get the exact figure from their vertices without the shader path; written into the dump's sidecars and the `[TEXDUMP]` summary with the note that occluded fragments count. Test: the generated shader text of `d3d8_combiners_hlsl.c` and `d3d8_combiners_msl.c` for the existing fixture set with the trace off is byte-identical to the current output; the fold from a synthetic buffer; the goldens in 1.8.
